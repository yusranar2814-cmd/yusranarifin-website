# Yusran Arifin — Personal Website

Foundation for a professional, multi-page personal website built with Next.js App Router, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Content directories

- `content/work`: selected-work entries and future case studies.
- `content/insights`: future Markdown or MDX articles.
- `content/products`: future product entries.

The current routes are intentionally structural only; final editorial copy and imagery have not been added.
